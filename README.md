# Static IP Playbook

一套可复用的静态住宅 IP 操作手册：采购、验价、接线、健康检查、续命、排障。

## 里面有什么

- `SKILL.md`：完整方法。先定需求（国家、城市、静态、独享、住宅/ISP 五项），再比价、下单核验、三种接法（直连、分流、经 VPS 链式转发）、上线前健康检查、到期续命、常见排障。
- `skill.yaml`：skill 描述文件。

## 使用场景

- 海外 AI 模型与 SaaS 订阅：部分海外服务仅面向特定地区开放注册与付费，静态住宅 IP 提供稳定的地区一致出口
- 海外社媒账号运营：用固定出口管理海外市场账号，保持登录环境稳定
- 跨境电商与独立站运营：管理海外店铺，查看当地市场的价格与页面展示
- 海外市场调研：查看不同地区的搜索结果、广告投放与竞品页面
- 产品多地区测试：验证网站与应用在不同地区的访问与展示效果

## 怎么用

按 `SKILL.md` 的顺序走。关键纪律：先验出口再碰目标账号；先对结账总价再付款；到期前续命，优先延长原单保住同一个 IP。
